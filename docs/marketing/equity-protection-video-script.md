# Equity-Protection Video Script Pack

For the D2C cold-traffic ads (Module 3, Channel 2 of the SCC marketing blueprint). Three lengths: 30s (hook + 1 CTA), 60s (hook + proof + CTA), 90s (full equity-protection narrative).

## Production specs

| Spec | Value |
|---|---|
| **AI presenter** | HeyGen or Synthesia — Black male, business-casual button-down (light blue or white preferred), age range 35–50, warm professional tone |
| **Voice** | ElevenLabs Voice — confident, conversational, mid-tone male. Recommended voice: "Adam" or similar warm baritone. Pacing ~150 wpm with deliberate pauses on key numbers |
| **Background** | Neutral home interior OR plain studio with soft warm lighting. NOT a generic AI gradient. If using a stock interior, prefer a finished room (kitchen island, living room) over construction sites — the angle is equity, not work-in-progress |
| **Captions** | Auto-generated, large font, bottom-third position. Most Meta viewers watch with sound off. |
| **Brand overlays** | SCC logo in upper-left at low opacity (15%) the entire spot. "NC GC License #107724" small text in lower-right corner from second 1 onward. **Required for compliance.** |
| **Aspect ratios** | 9:16 (Reels / Stories) PRIMARY, 1:1 (feed) SECONDARY, 16:9 (Google YouTube) TERTIARY |
| **CTA card at end** | 2-second hold on "southerncitiesconstruction.com/guide/pre-listing-checklist" with SCC logo + NC GC #107724 |

## What to feed into ElevenLabs / HeyGen

**To produce the videos:**

1. **HeyGen**: Choose a Black male avatar (HeyGen's "Marcus" or similar warm professional). Upload the script. Select voice → ElevenLabs voice integration (HeyGen supports ElevenLabs API), pick "Adam" voice. Set background: neutral home interior or studio. Render at 9:16 for the 30s + 60s. Render at 16:9 for the 90s YouTube version.

2. **Synthesia alternative**: Same plan, different avatar library. Pick a Black male presenter in button-down. Pair with ElevenLabs voice via export.

3. **Pure ElevenLabs (voice-only)**: If you go voice-only (no on-screen presenter), Combine with stock b-roll in CapCut or Premiere. Script reads at ~150 wpm, so 30s ≈ 75 words, 60s ≈ 150 words, 90s ≈ 225 words.

**Compliance check before publishing:**
- [ ] SCC logo visible throughout
- [ ] "NC GC License #107724" visible at least 5 seconds
- [ ] Closing CTA card includes license number + URL
- [ ] Captions auto-generated and accurate
- [ ] No false claims (e.g., "guaranteed to save $20K" → say "could save you $20K" or use the average framing)
