## Launch plan

**Day 1–5 — Learning phase:**

Run **#1 (Brutal accusation), #3 (Spreadsheet fairy tale), and #5 (Binary identity)** as separate ad sets to the same audience. $20/day each. $60/day total. 5-day learning.

Targeting (per `lm1-avatar.pdf`):
- NC + 50mi radius around Charlotte / Raleigh / Greensboro / Wilmington / Asheville
- Age 30–55
- Interests: BiggerPockets, real estate investing, BRRRR, real estate flipping, DealMachine/Propstream/PropertyRadar
- Detailed targeting expansion OFF
- Exclude: realtors, mortgage brokers, anyone who already converted

**Day 5 review:**
- **Sub-$10 CPL** → scale that ad set to $50/day
- **$10–$20 CPL** → keep at $20/day, iterate the headline
- **Above $20 CPL** → pause and write new variant (probably try persona-specific deal hooks)

**Day 14–21:**
- After 100 PDF downloads → build 1% NC lookalike audience
- After 25 CO1 buyers → build 1% NC lookalike of buyers (3–5x more efficient)
- Add the new ad set targeting lookalikes at $30/day
