# Southern Cities Construction — One-Page Fulfillment Map

**Operating rule**: Southern Cities owns judgment, pricing, recommendations, contractor decisions, change orders, QA, and accountability. White-label vendors run production tasks only. No vendor speaks for Southern Cities.

## Fulfillment models
A. Mostly in-house — judgment-heavy advisory
B. White-label assisted — SC judgment with vendor production support
C. Mostly white-label with SC QA — vendor runs the cycle, SC approves
D. Subcontracted field production — trade labor + vendor admin, SC controls
E. Not safe to white-label execution — admin layer only behind SC

### Contractors
- Permit Administration — C (permit coordinator, doc controller, inspection scheduler)
- Inspection Scheduling Support — C (inspection scheduler, remote admin)
- Admin Support for Active Jobs — C (remote admin, doc controller, CRM coordinator)
- Construction Oversight Support — B (AEC VA, photo runner, doc controller)
- Contractor back-office support plans — C (bookkeeper/admin, CRM coordinator, permit coordinator, inspection scheduler)

### Developers / Landowners
- Project Review — B (AEC VA, estimator)
- Budget & Scope Review — B (estimator, AEC VA)
- Permit Administration + Construction Oversight — Split: permit half C (permit coordinator, doc controller, inspection scheduler); oversight half E (admin only)
- Project Control Retainer — B (CRM coordinator, AEC VA, doc controller)
- Execution Oversight Retainer — E (admin layer only)

### Full Contracting (Renovations, Rehabs, New Builds, Additions)
- Model: D
- Field labor: trade subcontractors
- Precon/admin support: estimator, AEC VA, drafting/CAD, permit coordinator, inspection scheduler, materials procurement, doc controller, CRM coordinator, bookkeeper/admin, photo runner
- Southern Cities controls: sales, contract, scope, pricing, sub selection, schedule, field management, quality, safety, change orders, payment approvals, warranty, licensing

## Universal flow
1. SC intake
2. SC scope confirmation
3. Vendor work request with templates, deadline, red flags
4. Vendor production
5. SC QA
6. SC final recommendation
7. SC delivers to client
8. CRM follow-up
9. Upsell into next stage
10. Archive

## Standard
Southern Cities is the construction control company. The backend can scale through productized vendor pods, but the brand, trust, and judgment layer must always remain Southern Cities.
